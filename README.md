# 공부 플래너

HTML, CSS, JavaScript로 만든 개인 공부 플래너입니다.

## 다운로드 및 실행
1. [study-planner.zip](./study-planner.zip)을 내려받습니다.
2. 압축을 푼 뒤 `study-planner/index.html`을 브라우저에서 엽니다.
3. 별도 설치나 서버 없이 사용할 수 있습니다.

## 주요 기능
- 오늘 할 일 및 완료 현황 관리
- 주간 공부 기록과 과목별 시간 확인
- 과목별 등급 기록
- 모의고사 오답 및 보충 계획 정리

## 데이터 저장과 개인정보
- 앱에서 입력한 기록은 현재 브라우저의 `localStorage`에 저장되며 서버로 자동 전송되지 않습니다.
- 공개용 압축본의 `data/seed.js`는 빈 초기 데이터로 바꾸었습니다. 실제 성적, 오답 번호, 시간표는 포함하지 않았습니다.
- 데이터 백업 JSON에는 개인 학습 기록이 포함될 수 있으므로 공개 저장소에 커밋하지 마세요.
